# 🚀 Fastify Auth API with Prisma

مشروع متكامل لإنشاء نظام تسجيل دخول (Authentication) باستخدام **Fastify** و **Prisma ORM**. يتميز النظام باستخدام **JWT** المخزن في **Cookies** لتوفير أمان عالٍ وسهولة في الاستخدام.

## 🛠 التقنيات المستخدمة
* **Backend:** [Fastify](https://www.fastify.io/)
* **ORM:** [Prisma](https://www.prisma.io/)
* **Database:** PostgreSQL (Docker/Local)
* **Authentication:** JWT & Cookies
* **Validation:** Zod (Optional)
